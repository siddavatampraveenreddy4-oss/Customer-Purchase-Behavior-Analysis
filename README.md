# Customer-Purchase-Behavior-Analysis
Exploratory Data Analysis of Online Retail transactions using Python, Pandas, NumPy, Matplotlib and Seaborn.
# Customer Purchase Behavior Analysis

## Project Overview
This project focuses on analyzing online retail transaction data to understand customer purchasing behavior, sales performance, and product trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Data cleaning and preprocessing
- Customer purchase behavior analysis
- Repeat vs one-time customer analysis
- Top-performing products by revenue
- Country-wise sales analysis
- Daily order trends
- Customer revenue analysis

## Key Findings
- Identified top-performing products based on revenue.
- Analyzed repeat and one-time purchasing patterns.
- Compared sales performance across countries.
- Explored order trends across different weekdays.

## Dataset
UCI Online Retail Dataset: https://archive.ics.uci.edu/dataset/352/online+retail

- Customer_Purchase_Analysis.ipynb – Complete analysis and visualizations.
